===========================================================================
CAMINHO DO APK — o que voce roda
===========================================================================
  npm install
  npm run android:add
  npm run android:sync
  npm run android:prepare    (gera icones/splash + aplica permissoes, AdMob, nome e versao)
  npm run android:apk        (APK de teste)
      -> android\app\build\outputs\apk\debug\app-debug.apk

APK assinado para mandar para outras pessoas: secoes 3 e 4 de docs/APK.md
(keystore fora do projeto, senhas so por variavel de ambiente).

Fora da Play a compra "remover anuncios" NAO funciona — o faturamento da Play
so atende app instalado pela loja. O config ja esta em billing: 'none', entao os
botoes de compra aparecem ocultos. Anuncio (AdMob) continua funcionando e a conta
do AdMob e gratis.

===========================================================================
CAMINHO DA PLAY — os mesmos comandos, mas troca android:apk por
===========================================================================
  npm run android:open       (Android Studio > Build > Generate Signed Bundle > AAB)
e segue a secao 6 de docs/PLAY-STORE.md (ficha, Data Safety, classificacao).
La voce precisa voltar billing para 'play' e criar o produto remove_ads_once.
